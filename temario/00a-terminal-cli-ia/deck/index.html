¿Qué es una TERMINAL?

  • Programa donde escribís comandos de texto en vez de clickear botones.
  • Mismo resultado que con el mouse, pero repetible y más rápido — no hace falta re-clickear cada vez.

// con mouse (gui)
Explorador de archivos → doble clic en la carpeta → clic derecho → "Abrir con…" → esperar que cargue el programa.
// con terminal
cd proyecto && code .

Un comando, mismo resultado — y repetible sin volver a clickear.
texto, no clicks repetible y más rápido después: también git

man · token

man token

¿Qué es un token?

  • Unidad mínima de texto que procesa el modelo — no es lo mismo que una palabra.
  • Puede ser una palabra completa, un pedazo de palabra, o un signo de puntuación.
  • El consumo (créditos, límites) se mide en tokens — no en mensajes ni en palabras.
"Necesito refinar esta historia de usuario"
→ Necesito| refin|ar| esta| historia| de| usuario
→ 7 tokens para 6 palabras (aprox.)
// regla rápida
~4 caracteres ≈ 1 token en inglés. En español varía más por acentos y conjugaciones.
// por qué importa
El consumo (créditos, límites) se mide en tokens — no en mensajes ni en palabras.
unidad mínima de texto no es = 1 palabra así se factura el consumo
concepto08 / 15

Un token es la unidad mínima de texto que procesa el modelo — no es exactamente una palabra, puede ser un pedazo de palabra o un signo de puntuación. Todo lo que le mandan y todo lo que les responde se mide en tokens.

man · context-window

man context-window

¿Qué es la ventana de contexto?

  • Cantidad máxima de tokens que el asistente puede tener "en la cabeza" a la vez.
  • Ahí entran: tus mensajes + los archivos que leyó + sus propias respuestas — todo junto.
  • Si se llena, el asistente empieza a perder detalle de lo dicho al principio de la charla.
# tu conversación hasta ahora
[███████████████░░░░░░░░░] 62% de 200.000 tokens usados

# en criollo: ≈150.000 palabras ≈ un libro de 400 páginas
// qué entra ahí
Tus mensajes + archivos que leyó + sus respuestas — todo junto, en la misma ventana.
// si se llena
El asistente empieza a perder detalle de lo dicho al principio de la charla.
memoria activa máximo de tokens simultáneos se puede llenar
concepto09 / 15

Es la cantidad máxima de tokens que el asistente puede tener "en la cabeza" al mismo tiempo. Si la conversación es muy larga, puede llenarse — y el asistente empieza a perder detalle de lo que se dijo al principio.

Créditos: 5hrs vs. semanales

  • Dos modelos de consumo: reset cada 5 horas de uso activo, o reset semanal.
  • Conviene revisar cuál tiene tu plan (Claude Pro, ChatGPT Plus/Codex) antes de una jornada larga.
  • Quedarte sin crédito a mitad de una tarea real es evitable si sabés qué modelo tenés.
// modelo A
reset cada 5hrs
Se renuevan por bloque de 5 horas desde tu primer mensaje de la sesión.
// modelo B
reset semanal
Se renuevan una vez por semana, sin importar cuándo los usás.
# escenario: jornada de 8hs seguidas
modelo A → te quedás sin crédito a mitad de la tarde
modelo B → seguís, pero el lunes arrancás desde cero
2 modelos de consumo revisá cuál tiene tu plan
