# curso-ai-powered

Repositorio de trabajo que recibe el alumno del curso **AI-Powered QA**. A diferencia de
`../template-ai-powered/` (repo completo y final, de uso interno del instructor), este repo
**solo contiene lo que el alumno ya vio en clase** — se construye de forma incremental, tema a
tema, según lo que registra `../temario/control-general.md`.

## Estado actual

**Tema 00a — Terminal, CLI y primer asistente IA: dictado.** El alumno instaló Warp, Node.js y un
runner de IA (Claude Code CLI o Codex CLI), y este repo ya tiene `README.md` y
`AGENTS.md`/`CLAUDE.md` (memoria de IA).

`.git` quedó inicializado acá como efecto colateral: Warp pidió registrarse con cuenta de GitHub,
así que esa cuenta y el repo remoto se crearon en la práctica de este tema. La clase operativa de
Git (`fetch`/`status`/`pull`/`push`) sigue siendo contenido del Tema 00b, todavía no dictado — no
uses comandos git más allá de lo que Warp haya hecho por vos. Ver `../CLAUDE.md`.

## Cómo se actualiza

Cada vez que el instructor confirma "el alumno ya vio el tema X", se revisa
`../temario/<tema>/control-archivos-herramientas.md` y se copian/crean acá solo las piezas
correspondientes a ese tema — nunca contenido de temas futuros.
