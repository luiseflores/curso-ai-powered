# curso-ia-powered

Repositorio de trabajo que recibe el alumno del curso **IA-Powered QA**. A diferencia de
`../template-ia-powered/` (repo completo y final, de uso interno del instructor), este repo
**solo contiene lo que el alumno ya vio en clase** — se construye de forma incremental, tema a
tema, según lo que registra `../temario/control-general.md`.

## Estado actual

Ningún tema fue dictado todavía. Este repo está vacío a propósito.

**Sin `.git` inicializado.** El sílabo actual enseña Git/GitHub solo a nivel conceptual (no hay
clase operativa de comandos git) — hasta que eso cambie o el usuario lo pida explícitamente, este
repo no se versiona con git. Ver `../CLAUDE.md`.

## Cómo se actualiza

Cada vez que el instructor confirma "el alumno ya vio el tema X", se revisa
`../temario/<tema>/control-archivos-herramientas.md` y se copian/crean acá solo las piezas
correspondientes a ese tema — nunca contenido de temas futuros.
